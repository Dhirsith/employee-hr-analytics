## Provenance limitation

The Kaggle copy is a re-upload/distribution source, not asserted to be the original authoring source. Its description points to IBM's historical Watson Analytics article: <https://www.ibm.com/communities/analytics/watson-analytics-blog/hr-employee-attrition/>. That legacy IBM article/download endpoint was not accessible during the 2026-09-25 review, so the original distribution and original license statement could not be independently revalidated. The project records the Kaggle metadata as presented, retains attribution, and does not redistribute the raw dataset.

## Dataset scope

The downloaded CSV contains 1,470 rows and 35 columns. It has one record per fictional employee, no date fields, and a Yes/No attrition label. The sample is static and not representative evidence about a real workforce.
